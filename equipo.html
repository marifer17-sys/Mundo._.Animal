Objetivo del proyecto

El objetivo de este primer proyecto es crear un sitio web informativo sobre el tema de los animales utilizando únicamente el lenguaje HTML y demostrando el uso de diferentes etiquetas para organizar información.

En nuestro sitio presentamos información, imágenes, listas, una tabla , un formulario de contacto y una buena presentación.
